## Setup
1. To setup this program, download the zip file and extract it.
2. Then use anaconda's jupyter lab using python 3.10 with matplotlib and ipywidgets
3. Connect to the extracted file and open menu.ipynb
4. Finally, run all notebook cells
## What does it do?
- This program allows for a GUI interface in python to search for, rent, and return music
- It also includes an inventory pruning feature to view rental frequencies of records
- Any updates when running this script will update the respective .txt files to be used as a local database
- This program also accesses .pyc files while not having full unauthorised access to it
